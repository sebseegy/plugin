## Tier Descriptions

### Tier 1: Essential ($15,000)
**Target:** A single team looking to automate a specific process.
**Scope:** 1 basic use case — something like automating status updates, categorizing requests, or surfacing data insights.
**Example:** An operations team uses AI for Project status & risk visibility. Sidekick summarizes statuses/risks; AI Blocks generate daily project health summaries.

### Tier 2: Advanced ($30,000)
**Target:** Teams ready to transform multiple processes or cross-functional workflows.
**Scope:** Up to 2 basic use cases OR 1 advanced use case — e.g., connecting intake automation to project tracking, or sales qualification to pipeline management.
**Example:** Portfolio execution with auto-routing and executive dashboard views. AI Blocks auto-classify and assign work; Vibe builds leader-focused monitoring (OKR monitoring); workflows automate risk-based reassignment.

### Tier 3: Premier ($45,000)
**Target:** Organizations ready to embed AI across complex, interconnected operations spanning multiple departments with governance and advanced automation needs.
**Scope:** Up to 5 basic use cases OR 2 advanced use cases.
**Example:** HR leverages AI to streamline hiring, onboarding, and people health. AI Blocks extract resume data; Sidekick summarizes candidate fit; Vibe builds onboarding command centers. Finance is pinged automatically for budget decisions; Sidekick handles ad hoc inquiries; Vibe generates approval command centers for leadership.

## Scoping Rules

- The tier limits are guardrails — hold to use case limits. If you have concerns about scope, raise with your team lead.
- "Basic" use case = single-team, focused process automation (one input → one AI-driven output chain)
- "Advanced" use case = cross-functional workflow, multiple AI tools integrated, more complex data flows
- If requirements are beyond scope: contact Account Manager about additional options through monday.com or certified partner network
- **Tier limits are not flexible without team lead approval** — do not over-promise scope to win the deal

---

## Scoping Tips

- Start by counting use cases — if the client has more than 1 distinct workflow that needs AI, likely Tier 2+
- Use the user count as a quick filter: 50 users = Tier 1 ceiling, 250 = Tier 2, 500 = Tier 3
- If the client mentions multiple departments or cross-functional data flows, move to Tier 2 minimum
- Vibe apps and AI Agents almost always push toward Tier 2+ due to complexity
- Even within a standard implementation (non-AITP), ICs should use Sidekick for rapid prototyping in POC phases

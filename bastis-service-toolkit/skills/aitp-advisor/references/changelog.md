# aitp-advisor — confirmed release changelog

Dated log of changes relevant to the AI Transformation Package (AITP)
methodology and delivery, newest entry first, fed automatically by `weekly-pulse`
each time it runs. Covers new AI features that expand AITP scope (new tools
to include in discovery, new adoption levers), methodology updates, enablement
content changes, org-sharing or governance capabilities relevant to AITP
deployment, and any commercial changes (credit models, add-on pricing) that
affect AITP scoping conversations.
